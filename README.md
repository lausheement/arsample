# To-Do List App

This repository contains a small browser-based to-do list app with local storage persistence.

## Features

- Add tasks
- Mark tasks as complete/incomplete
- Delete tasks
- Automatically persist tasks in `localStorage` so they remain after refresh/restart

## Run

Open `/home/runner/work/arsample/arsample/index.html` in a browser.

You can also serve it locally, for example:

```bash
cd /home/runner/work/arsample/arsample
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
