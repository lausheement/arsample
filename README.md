# Arsample Android To-Do App

This repository contains a native Android to-do list app built with Kotlin and Jetpack Compose.

## Features

- Add tasks
- Mark tasks complete/incomplete
- Delete tasks
- Persist tasks locally using Android SharedPreferences

## Open in Android Studio

1. Open Android Studio.
2. Choose **Open** and select `/home/runner/work/arsample/arsample`.
3. Let Gradle sync complete.
4. Run the `app` configuration on an emulator or device.

## Build and test from command line

```bash
cd /home/runner/work/arsample/arsample
./gradlew assembleDebug
./gradlew test
```
